# Batch Process Practice

## 주문 자동 취소 배치

### 목적
입금 대기 상태의 주문이 일정 시간 내 결제되지 않으면 자동 취소한다.

### 프로세스

```text
주문 생성
  ↓
PAYMENT_WAIT 상태
  ↓
24시간 경과
  ↓
배치 실행
  ↓
미결제 주문 조회
  ↓
주문 취소
```

### 처리 결과

- 주문 상태 → CANCELED
- 재고 복구
- 주문 취소 이력 생성

---

## 휴면 회원 전환 배치

### 목적
장기간 로그인하지 않은 회원을 휴면 상태로 전환한다.

### 프로세스

```text
회원 가입
    ↓
서비스 이용
    ↓
1년 미접속
    ↓
배치 실행
    ↓
휴면 회원 전환
```

### 처리 결과

- 회원 상태 → DORMANT
- 개인정보 분리 보관
- 휴면 안내 메일 발송

## 장바구니 정리 배치

### 목적
장기간 방치된 장바구니 데이터를 정리한다.

### 프로세스

```text
상품 담기
    ↓
90일 미사용
    ↓
배치 실행
    ↓
장바구니 삭제
```

### 처리 결과

- 장바구니 데이터 삭제
- 저장 공간 확보

## 정기 구독 결제 배치

### 목적
구독 서비스 이용 고객의 정기 결제를 수행한다.

### 프로세스

```text
구독 신청
    ↓
결제일 도래
    ↓
배치 실행
    ↓
PG 결제 요청
    ↓
성공/실패 처리
```

### 처리 결과

- 결제 성공 → ACTIVE 유지
- 결제 실패 → FAILED 상태 변경

통계 저장
